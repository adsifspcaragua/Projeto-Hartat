# Sobre o Projeto
O projeto foi desenvolvido com o objetivo primordial de ampliar a visibilidade institucional e atrair novos visitantes e apoiadores ao oferecer uma plataforma digital acessível que divulga a cultura dos povos originários, incluindo exposições, oficinas de cerâmica e sessões de cinema feitos dentro do espaço cultural. Além disso, umas das principais funcionalidades presentes no sistema é um [Sistema de Gerenciamento de Conteúdo](https://github.com/LuisPerossi/hartat-dashboard) que permite ao cliente gerenciar todo o conteúdo de forma autônoma e sem conhecimentos técnicos, incluindo operações de CRUD (criar, ler, editar e apagar) para postagens, eventos e acervos. 

# Tecnologias Utilizadas
O projeto foi desenvolvido utilizando as seguintes tecnologias:

| Camada | Tecnologia |
|---|---|
| Linguagem | **JavaScript ES17** |
| Framework | **React.JS** |
| API | **CloudFlare Functions** |
| Banco de Dados | **SQLite (CloudFlare D1)** |
| Testes e Gerenciamento de Recursos | **CloudFlare Wrangler** |
| Build Tool | **Vite** |

# Instalação
Para utilizar o projeto localmente você deve:
1. Clonar esse repositório:
   ```bash
   git clone https://github.com/adsifspcaragua/Projeto-Hartat.git
   cd projeto-hartat
   ```
   
3. Instalar as dependências:
   ```bash
   npm install
   ```
   
4. Rodar o website e abrir ele no localhost que aparecerá em seu terminal:
   ```bash
   npm run dev
   ```
